# Курс PyClass (файли в репозиторії)

Контент модулів 1–4 лежить у `content/modules/*.json` і збирається через `content/course.ts`.

## Синхронізація в БД

```bash
pnpm content:sync
```

Скрипт **upsert** за стабільними `slug`:

- якщо рядка немає — створює з `repo_managed=true`;
- якщо є і `repo_managed=true` — оновлює поля з репо;
- якщо є і `repo_managed=false` — **пропускає** (редагування вчителя в UI);
- **ніколи не видаляє** уроки/вправи/питання (збережені здачі студентів лишаються).

### Безпечна поведінка при правках учителя

Будь-яке змістовне редагування модуля / уроку / вправи / питання через UI виставляє `repo_managed=false`. Наступні `pnpm content:sync` ці рядки не перезаписують. Щоб знову підтягнути з репо — у БД вручну постав `repo_managed=true` для потрібного slug.

Демо-контент зі `db:seed` прибрано: seed лише забезпечує групу DEMO10A і вчителя. Курс наповнюється sync.
